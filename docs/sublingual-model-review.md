## 1. 结论与修改边界

上一轮修订解决了吞咽支路隐藏慢清除、theta=0 不等于口服及峰值漏采样的问题，但将 E2 的消失全部当作不再返回的损失，**没有显式表示 E1/E1S 回转**。因此不能用那一版的极低尾值证明人体 24 h 时已经没有外源 E2 贡献。

本轮采用机制启发的 **E2 ↔ E1 ↔ E1S 三池网络**，给口服 E2/EV 和新版舌下共同使用。保留快速黏膜吸收和较慢吞咽吸收；只输出 E2 池，不把 E1、E1S 的量或雌激素活性直接加到 E2 浓度中。

这是一个**可检验、质量守恒的简化假设模型，不是临床拟合完成的“真实人体曲线”**。现有资料不足以唯一识别全部输入比例、回转速率和分布容积。不能因用户认为 8 h 不应下降很多，就把尾部任意抬高；早期快速下降与低幅长尾可以并存。

改动范围：口服 E2/EV、新版舌下 E2/EV。旧版舌下、注射、凝胶、贴片、CPA/T 的药量内核保持不变。口服也修改是为了让新版舌下 theta=0 的完整轨迹仍等于口服，而不是悄悄让吞咽部分使用另一套人体代谢。原有个体校准参数不能视为在新结构下自动有效，应重新核对。

### 其他产物和检测含义

- E1 本身有雌激素活性，但“有活性”不等于血液化验中的 E2；此处只计算 E1→E2 的物质量。
- E1S 的脱硫酸化、E1 与 E2 的氧化还原使回转成为可能；并非每一个进入 E1S 的分子都必然回到循环 E2。
- E2 硫酸酯、葡萄糖醛酸结合物及其他产物未逐一拆池；当前将未表示的去路折叠为有效流出。**这不是宣称所有这些产物在生理上都不可逆或没有肠肝循环**。
- 未显式表示肠道转运延迟、组织内局部代谢、分布室、蛋白结合动力学或肝功能差异；不能用单个 E2 浓度辨认这些机制。
- 这里的 E2 池是用于估计血清 E2 剂量贡献的有效池，不专指未结合的“游离 E2”。未添加任意内源基础值，也未模拟检测方法交叉反应。

## 3. 数学结构：分开“E2 消失”和“整个雌激素网络流出”

状态 `x = [A2, A1, AS]ᵀ`，全部使用 **mg E2 摩尔等效量**。同一分子的转化不会因硫酸基质量增加而创造剂量。

```text
x'(t) = M x(t) + b_fast ka_fast exp(-ka_fast t)
                 + b_slow ka_slow exp(-ka_slow t)

M = [ -ke          k12                  0  ]
    [  0.5 ke     -ln(2)/1h           ks1 ]
    [  0           0.54 ln(2)/1h      -ks  ]

k12 = 0.06 * ln(2)/1h * strength
ks  = ln(2) / sulfateHalfLifeH
ks1 = 0.21 * ks * strength
```

对原药/酯剂量 `D`，分子量换算 `r = 1`（E2）或 `272.38/356.50`（EV）：

```text
b_fast = D r theta * [0.28, 0, 0]
b_slow = D r (1-theta) * [F, 0.1*(1-F), 0.5*(1-F)]

ka_fast = 2.4 h^-1
ka_slow = 0.32 h^-1（E2）或 0.05 h^-1（EV）
口服 = theta=0
Delta C_E2(t) = A2(t) * 1e9 / (2.0 * weightKg * 1000) pg/mL
```

吸收率、分流 theta、0.28 幅度和有效分布容积为项目继承的经验参数。EV 的 0.05 尤其需进一步研究，不能视为真实的酯裂解速率。theta 档位 0.01/0.04/0.11/0.18 仍兼容旧记录，非按含服分钟数实测的吸收比例。

### 明确的先验，而不是从研究中识别出的参数

| 模型假设 | 默认值 | 解释 |
| --- | ---: | --- |
| E2 总消失速率 ke | 0.41 h⁻¹ | 沿用项目有效参数；其中 50% 通量进入 E1，50% 为未表示流出。添加回转后它不再等于整个曲线的终末清除率。 |
| E1 池周转 | ln2 / 1 h | 周转半衰期 1 h 的先验；6% 周转进入 E2，54% 进入 E1S，40% 未表示流出。 |
| E1S 池周转 | ln2 / 12 h | 12 h 是先验，不是文献拟合值或 E2 的终末半衰期。21% 周转进入 E1，79% 未表示流出。 |
| 首过 E1/E1S 输入 | 剩余非直接 E2 剂量的 10%/50% | 经验分配，不是从示踪实验读出的生物利用度；总输入不超过给药摩尔量。其余剂量不进入所表示的循环池。 |
| 回转敏感性 strength | 1（允许 0–3） | 同时缩放 E1→E2、E1S→E1 的分支通量；保持各池总周转固定，差值改变未表示流出。0 关闭对 E2 的回补。 |
| E1S 周转敏感性 | 12 h（允许 4–36 h） | 用于评估尾部对假设的敏感性，不是有临床依据的正常范围或个人参数置信区间。 |

0.54/0.21 等数值受示踪结果的量级启发，但**不能把多次经过循环的 tracer transfer factor 解释为此处的瞬时分支概率**。这些数值在此仅是待拟合先验，模型不声称重现 Ruder 或 Longcope 的转移比例。E2→E1 的比例、首过分配和 E1/E1S 周转均没有在本次被数据识别。

默认下网络各列和为负，所有转化流非负；包括未表示流出时总摩尔量守恒。strength 上限 3 下 E1 返回+硫酸化份额仍小于 1，E1S 返回份额也小于 1，不会凭空生长。

### F 的语义和暴露

`e2_oral_bio` 默认 0.03 现在明确作为**直接进入 E2 池的输入系数**，不是包含代谢物回转后的总暴露。界面标签已相应修改。历史经验 F 本来可能吸收了部分回转效应，不能保留其旧解释再声称新增储库后仍是原校准；目前没有临床数据将这些效应唯一拆开。

同样，`getBioavailabilityMultiplier` 对新版/口服返回直接输入系数，不能用 `D*F/ke` 计算现在的全时段 E2 AUC。正确的模型积分是：

```text
Integral A2 dt = first_component(-M^-1 * (b_fast + b_slow))
```

E1/E1S 不直接进入 E2 曲线；只有回转产生的 A2 参与积分。重复给药叠加各次完整状态响应，因此已存在的储库自然累积，不需要在每次给药时凭空添加一个基础浓度。

## 5. 求解与显示

- 对可逆三对角网络作对称相似变换和 3×3 Jacobi 特征分解，每组参数只计算一次；按每个衰减模态与一阶吸收作解析卷积，每个时点 O(3)。缓存最多 24 组参数，已编译剂量不会被后续个人设置改变。
- 接近相等速率时用连续极限，其他情况用 `expm1` 避免相消误差；零剂量/给药前输出为零。
- strength=0 恰好回到无回转 Bateman 模型，口服在此极限也等于历史内核。
- 生命周期包含网络最慢特征衰减率，以 `ln(1e10)/min(rate)` 留数值余量；它不是人体的“药效归零时刻”。无 8/24 h 强制清零。
- 保留上轮的所有历史剂量局部密集采样修复，包括新版的 0.125/0.75/1.25/1.5/3 h，避免 14 天预测窗口把近期尖峰样本剔除。

## 7. 后续真正提高准确性的条件

需要明确制剂、剂量、含服过程、近期完整给药史、采血时刻，并获得密集 E2/E1/E1S 数据（含足够长尾窗），区分基础值与剂量增量，再做可识别性分析和联合拟合。不能只用一个 8 h 或 24 h 血值同时估计吸收、分布、首过和所有回转通量，也不能据此直接建议用药剂量或间隔。
